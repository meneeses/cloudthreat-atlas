# Roadmap

## Milestone 1 — Portfolio demo

- Synthetic Contoso Health snapshot
- Interactive graph, filters, details, and Story Mode
- Precomputed remediation simulations
- GitHub Pages deployment

## Milestone 2 — Analysis engine

- Deterministic graph and risk score
- Go-native rules
- Dynamic attack path analysis and simulation
- JSON, HTML, Markdown, and SARIF reports

## Milestone 3 — Read-only Azure collector

- Azure CLI and `DefaultAzureCredential` authentication
- Resource Graph queries for compute, network, storage, secrets, databases, identities, and RBAC
- Redaction and local snapshot storage

## Milestone 4 — Product hardening

- Snapshot comparison
- Rule documentation and policy packs
- Release binaries with the embedded web application
- Architecture walkthrough and demo video
- Public launch material ([draft](launch-post.md))

## Future, separately budgeted

- Optional hosted collaboration
- Multi-tenant SaaS controls
- Scheduled scans and team workflows
- Additional cloud providers
